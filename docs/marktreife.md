# Marktreife: KI-LernApp

## 1. Inhalt

- Ein Kapitel vollständig ausbauen: Inhalt, Interaktion, Quiz und Erklärungen für Einsteiger ohne Vorwissen. Welches Kapitel, ist offen.
- Glossar-Begriffe in den Kapiteln erklären. Das Glossar gibt es bereits im Kapitel "KI einrichten".
- Später: die übrigen Kapitel (Prompting, Training, Tokens, Halluzinationen, Bias, Neuronale Netze, KI einrichten) nach dem Muster des ersten Kapitels ausbauen.

## 2. Funktion

- Fortschritt im Browser speichern, damit man beim nächsten Besuch weitermachen kann.

## 3. Qualität

- Test auf 320px bis 1440px Viewport.
- Tastaturbedienung für alle Bereiche.
- Sehr guter Kontrast nach höchstem Standard.
- Barrierefreiheit nach dem Gesetz, das der Nutzer nennt. Die genauen Paragrafen sind offen.
- Meta-Tags für Suchmaschinen und Link-Vorschauen.
- Code nach den Projektregeln: kein overflow-hidden, keine Schrift unter 14px, kein !important, JSDoc statt Kommentare.
